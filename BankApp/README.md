# Банковское приложение

## Архитектура

Использую VIPER, так как четко разделен функционал (бизнес-логика и представление), поддерживается масштабируемость приложения, хорошо тестируются модули по-отдельности

## Экраны приложения

1. Авторизация
2. Список фичей (счета, переводы, история операций)
3. Счета (список счетов с балансами)
4. Переводы
5. История операций

## Workflow

1. Авторизация

- Если пользователь уже зарегистрирован, то вводит логин и пароль, входит в аккаунт
- Если же не зарегистрирова, то вводит логин, пароль, подтверждение пароля, регистрируется
- Пользователя перенаправляет на экран со списком фичей

2. Список фичей

- Загружаются доступный функционал приложения (счета, переводы, история операций)
- Пользователь может выбрать функцию, после чего перейдет на соответствующий экран

3. Счета

- Подгружаются счета пользователя с балансами (возможны валютные счета)

4. Перевод

- Пользователь может совершить перевод с одного из счетов на другой

5. История операий

- Пользователь может просмотреть все операции, совершенные им
